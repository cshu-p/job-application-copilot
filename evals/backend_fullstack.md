# Backend / Full-stack Draft Evaluation

## Job Description

Job Title: Junior Full-stack Software Engineer

Responsibilities:
- Build frontend features using React and TypeScript.
- Develop backend APIs using Node.js and Express.
- Design and query relational databases.
- Implement CRUD workflows and integrate frontend and backend services.

Minimum Qualifications:
- Experience building a full-stack application.
- Familiarity with SQL, relational schemas, and foreign keys.
- Ability to debug integration issues.

Preferred Qualifications:

- Familiarity with transactions, stored procedures, and database triggers.
